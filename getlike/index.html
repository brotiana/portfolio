GetLike.io + tiktok task automation

Rôle full development
Technologies JavaScript, python.

Project description

getlike.io is a platform that offers tasks such as liking, following, and commenting on TikTok accounts and posts in order to earn money. This project automates those tasks.


Here is the workflow

Automated Task Processing Loop
1. Chrome Extension
Fetches all tasks from getlike.io
Sends tasks to Telegram user
2. User Backend
Filters completed tasks
Returns pending tasks to Extension
3. Chrome Extension
Retrieves: task link, task ID, TikTok username
Sends to user's Telegram
4. Backend
Executes task on TikTok APK
Uses ADB & UIAutomator2
5. Task Completion
User sends signal to Extension
6. Chrome Extension
Marks task as completed
Clicks "check" button
7. Fetch Next Task
Process loops continuously
⟲ LOOP
