Présentation du projet

HelpCercle

Rôle full development
Plateforme Web
Technologies JavaScript, Node JS, PHP, MySql

Project description

HelpCercle is a web application where users can either offer a service in exchange for money or post a request for a service they need.
There are basically two types of users: the first kind sells something like a skill or an account, for example. The second kind is looking to buy that skill or a specific service, and can post a request on the platform if they can't find what they need.
Users who post offers can also offer services carried out by AI agents. These AI-agent-powered services could include things like audio transcription, image background removal, sending messages to a list of 1000 emails, building a website, and so on.
Connecting an AI agent to the HelpCercle platform requires the site admin (me) to step in, since each AI agent offer needs its own custom-built interface tailored to what it does.

Features

  • Buyers and sellers can chat with each other directly.
  • Automatic deposits using cryptocurrency.
  • Real-time messaging and notifications using WebSocket.
  • Member profiles, transaction tracking, and history.
  • Affiliate system.
  • Users can offer 100% automated services powered by AI or scripts, by connecting their own server (running the system that performs the task) to the HelpCercle platform.
