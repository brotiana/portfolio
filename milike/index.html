About the program

Milike is a automation tool built to automate some action in instagram : like , follow , unfollow , comment , post story or publication , delete a post. The project combines a Python backend that interacts with Instagram private endpoints and a minimal web-based admin UI for scheduling and monitoring tasks.

  • Specifically in the video above, the script interacts with a Telegram bot called 'SmmKingdomtasks'. This bot pays for Instagram actions such as likes, follows, and comments. The script uses Telethon to intercept and execute these tasks.
  • Scheduler: tasks can be scheduled or run immediately from the dashboard; the scheduler respects configurable rate limits to avoid triggering platform protections.
  • Storage: uses a small SQLite database for queues, user credentials and task history.
