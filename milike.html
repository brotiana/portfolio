About the program

Milike is a lightweight automation tool built to assist social media operators in scaling basic Instagram workflows. The project combines a small Python backend that interacts with Instagram endpoints (or a headless browser when needed) and a minimal web-based admin UI for scheduling and monitoring tasks.

  • Core actions: automatically like posts, follow/unfollow accounts based on simple filters, post scheduled content, add comments and optionally delete posts.
  • Scheduler: tasks can be scheduled or run immediately from the dashboard; the scheduler respects configurable rate limits to avoid triggering platform protections.
  • Monitoring: an activity log shows recent actions and simple success/failure metrics; screenshots (like the one above) help verify results.
  • Storage: uses a small SQLite database for queues, user credentials (encrypted in production) and task history.

This demo is intended for learning and experimentation. In a production context, platform policies and legal constraints must be respected and appropriate rate-limiting, error handling and credential security must be implemented.
