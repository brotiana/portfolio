Project description

An Android app I built to automate the daily grind of paid task bots on Telegram.
SmmKingdomTasks bot posts simple jobs : liking, following and commenting on TikTok and Instagram accounts , and pays you for each one.
Instead of doing tasks manualy, this app automate all of these tasks and handles them on its own using Android's Accessibility Service.
Also, this application intercepts the Cloudflare verifications and calculations sent by the bot to counter automation (this APK bypasses all of that using AI , allowing it to run 24/7).

This application directly uses the phone's interface : performing clicks, scrolling, opening apps ...., which guarantees that Instagram and TikTok accounts won't be blocked, because the script acts as if it were a human.

Features

  • Full automation of like, follow , comment and captcha through the Accessibility Service.
  • A parameter that limits the actions to be performed, so as not to be restricted by either platform.
  • A log interface and a statistics interface showing earnings gained, completed tasks, and skipped tasks.

How it works

The automated task loop
1. Telegram bot
Sends a task (like / follow / comment)
2. Android app (APK)
Performs the action on TikTok / Instagram
3. Task done
Sending "Completed" to the bot → credit lands in your balance
