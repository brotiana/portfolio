Project description

SmmKingdomTasks + HelpCercle_bot est une application Android (APK) qui automatise l'exécution des tâches proposées par les bots Telegram SmmKingdomTasks et HelpCercle. Les tâches consistent à liker, suivre et commenter des comptes et publications sur TikTok et Instagram afin de gagner de l'argent.

L'application s'appuie sur le service d'accessibilité Android pour interagir avec les applications sociales et exécuter les tâches automatiquement. La logique métier est embarquée via Chaquopy, qui permet d'exécuter du code Python directement dans l'application Android.

Fonctionnalités

  • Automatisation complète des tâches de like, follow et commentaire via le service d'accessibilité.
  • Interaction avec les bots Telegram SmmKingdomTasks et HelpCercle.
  • Logique métier en Python embarquée avec Chaquopy.
  • Persistance des données locales avec SQLite.

Workflow

Boucle de traitement automatisé
1. Bot Telegram
Envoie les tâches (like, follow, commentaire)
2. Application Android (APK)
Détecte la tâche via Accessibility Service
Exécute l'action sur TikTok / Instagram
3. Tâche terminée
Confirmation envoyée au bot → gain crédité
