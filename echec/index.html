Chess game online

Rôle full development
Plateforme Web
Technologies JavaScript, Node JS, PHP, MySql

Project description

Chess Game Online is a web platform where you can play chess against other players online or practice against the computer. The game interface displays the board with full support for all chess rules : legal moves, castling, checkmate and keeps moves synced between both players in real time.
Players can also chat with their opponent during the game, right from the interface.
On the backend, the app is split into two parts: a Node.js server handles real-time communication between players through WebSockets (game rooms), while PHP and MySQL take care of data persistence like user accounts, match history, stats, and rankings.

Features

  • Sign up and account creation.
  • Invite a user to join a chess game.
  • Interface listing all online users, with the ability to send them a message.
  • Real-time move synchronization between players.
  • Play against the computer.
  • Full chess rules implemented (check, checkmate, stalemate, promotion).
  • Match history, stats, and player rankings .
  • Make a game public so other users can watch it live, or keep it private.
  • An option to watch public games currently being played online.
